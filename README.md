# Chinook-Music-Store-SQL-Analysis
Data-driven business insights and SQL analysis for the Chinook Music Store.


## Project Overview

This project explores the Chinook Music Store database using SQL Server. The objective is to answer real-world business questions and extract meaningful insights from sales, customers, artists, albums, playlists, and employee data.

Through a series of analytical SQL queries, the project identifies sales patterns, top-performing products, customer behavior, and revenue trends.

## Business Questions

The analysis answers several business questions, including:

### Sales & Revenue Analysis

* Which tracks have the highest sales quantity?
* Which tracks generate the highest revenue?
* Which genres generate the highest sales volume?
* Which albums generate the most sales?
* Which artists generate the highest sales?

### Playlist Analysis

* What are the most frequently added tracks to playlists?
* Which playlists contain the highest-selling tracks?

### Customer Analysis

* Who are the top 10 customers by total spending?
* Which countries generate the highest revenue?
* Which countries have the highest average order value?

### Employee Analysis

* Which employees generate the highest sales?
* How many customers does each support representative manage?

### Advanced Analysis

* What are the yearly sales trends?
* What are the longest tracks in the database?
* Which tracks are longer than the average track length?
* Which artists have tracks across multiple genres?
